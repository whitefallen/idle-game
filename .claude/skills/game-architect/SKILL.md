# Purpose

Defines architecture rules, modularity, server authority, feature-first organization, naming conventions and review checklist.

# Responsibilities

- Follow project architecture.
- Keep modules cohesive.
- Prefer reusable components.
- Write deterministic game logic.
- Avoid technical debt.

# Checklist

- Single responsibility
- Clear naming
- No duplicated logic
- Testable
- Extendable
- Server authoritative where applicable
