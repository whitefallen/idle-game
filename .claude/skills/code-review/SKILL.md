# Purpose

Review checklist covering SOLID, duplication, naming, performance, security, testability and maintainability.

# Responsibilities

- Follow project architecture.
- Keep modules cohesive.
- Prefer reusable components.
- Write deterministic game logic.
- Avoid technical debt.

# Checklist

- Single responsibility
- Clear naming
- No duplicated logic
- Testable
- Extendable
- Server authoritative where applicable
